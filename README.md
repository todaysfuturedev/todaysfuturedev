## Todays Future
Most construction software is built by people who have never priced a job.

I've priced a lot of them. Six years owning a roofing and construction company, twenty in consultative sales, now project support at a commercial GC in South Florida — building the tools the trade actually needs along the way.

**Working on**

- Contractor visibility auditing — scoring the five things that decide whether anyone finds a local contractor
- AI prompt systems for marketing and content operations
- Cinematic project showcases — React, Vite, three.js

**Stack** — TypeScript, React, Python, Node
